## 已实施的集中修正

| 修正 | 实际行为 | 保留边界 |
|---|---|---|
| 精确外置文档归属 | module manifest 可选 `context_paths`；模块 inputs-v2 排除其他模块明确私有文档 | 精确 Markdown、唯一 owner、禁止控制/源码/全局规则路径；共享输入优先；未知输入不排除；声明变更需重新验证 |
| 输入缺陷分类 | 缺必要设计输入/章节、未决标记等返回 `input-defect` / `repair-inputs`，不生成自动刷新命令 | 不把真实输入错误当作过期缓存；不自动批准设计变更 |
| 宿主修复派发 | 路由和最终汇合都读取顶层 `repair_guidance`；`diagnose` 停止等价刷新 | 首次合法修复仍允许；实际规范化命令和输入指纹共享重试计数，原期限/预算不变 |
| 交接与验证规则 | 一次准备工作树/命令/报告隔离；最终冻结前完成静态检查；按影响补验、引用已有有效证据 | 不新增强制计时台账、每命令文档或调度器；真实 API、UI、迁移门禁不降低 |

`context_paths` 是归属声明，不扩充 semantic checker 的扫描范围。明确契约仍用 `contract_paths`/`shared_paths`，文件继续遵循现有 Git 来源收集规则。旧范围不会自动获得新的排除语义；旧证据不重签、不追认。
