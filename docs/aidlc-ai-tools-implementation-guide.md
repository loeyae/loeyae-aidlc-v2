# AIDLC 5 实施指南

从用户目标、既有验收和授权继续工作。读取当前相关代码/设计，选择必要方法，持续实现、验证、审查和返修。具体规则只维护在 [执行规则](../core/knowledge/protocols/host-execution.md)，本指南不复制它。

局部表单 CR 从受影响组件及验证开始；校验、接口、权限和数据语义变化沿真实依赖扩大范围。续作从当前 Git、已有任务说明和原始结果开始，不恢复旧阶段指针。外部验收等待只保留对应待办，能独立实施的部分继续。

按需使用 [方法目录](../core/knowledge/methods.md)。必要质量标准见 [验证](../core/knowledge/protocols/verification.md)，授权见 [权限](../core/knowledge/protocols/permissions.md)，所有报告使用 [完成判定](../core/knowledge/protocols/completion.md)。没有下一阶段和空清单不能表示项目完成。

5.x 不提供旧受管执行模式；安装升级和历史资料处理见 [README](../README.md)。
