# 自主宿主输入优化

依据订单 r13 的真实输入分析：阶段提示词 201.8 KB、规则返回 174.0 KB，占实施新增输入字节的 76.7%；首次 READY 已有 17,027 token，末次请求 178,316 token。优化实际投喂路径，不变更质量标准、执行授权、期限、预算、业务输入或 P1/P2 边界。

| 项目 | 实施边界 | 验收 |
|---|---|---|
| N1 阶段任务视图 | Core 保持完整 directive；宿主只向模型默认展示当前任务、验收、规则/文档索引、限制、委托事项和诊断；原始结构可按需取回 | 捕获三阶段提示词离线对比；审批、Provider、UI、失败诊断与写入约束保留 |
| N2 按需规则与读取 | 长阶段规则有源文件内执行摘要和章节索引；全文/章节显式读取；仅数据库相关工作加载数据库规则；公开证据默认摘要 | fenced code 不能误作章节；未知规则保留原文；变更内容重新读取；相同内容引用复用且能强制重读 |
| N3 准入重入返修 | 记录原始 Core 重入响应，精确目标的合法证据返修交回已有有界 driver；未派发原动作；硬阻塞仍停止 | 使用短重入/driver 测试；原期限、预算、RED 和候选规则不变；无嵌套自动修复或无限重试 |
| N4 验证与分发 | 先短边界，再必要宿主集成，离线回放真实输入，十个 Harness 同步 | 不重复长前缀、不签发 H5、不创建试点；真实交付资格保持 HOLD |

摘要和复用都是模型阅读优化，不替代 Core 对当前来源的校验；文件 SHA 仍指原始字节。全文访问走同一权限、路径和预算边界。缓存仅存在同一 Gateway 生命周期中，不跨进程或后继会话继承，不通过创建新 thread 清空上下文。对权限、范围、审批、未知资源及不可自动修复的错误保留停止语义。

本轮不修改宿主平台必须注入的系统提示词，不承诺精确 token 或真实交付时间降幅。测量使用已捕获日志的 UTF-8 字节，真实宿主复跑留待后续复审。

## 实施结果

N1–N4 已完成工程实施。`host-model-input.mjs` 接入真实 Gateway 读取、Core 工具返回和阶段提示词，并纳入 HostRef 与 Codex 分发。公开证据只隐藏已知机械溯源字段；UC-D applicability/modes、测试映射、开放审查问题、错误和未知业务字段保持可见。未知规则保持全文；四份阶段/自主协议使用源文件内执行摘要与可按需读取的原始章节。原生替换通道同步支持全文请求。

重入处理与普通路由共用 continue/repair/stop 分类：同实例、无人工阻塞、Core 声明可执行的证据返修返回宿主，原模型命令不派发；已有 repair driver 使用原次数和期限处理。混合硬错误、审批/choices、跨实例、diagnose 和未知结果仍停止。原始公开 Core 重入响应写入既有执行事件，避免再丢失具体原因。

| 原试跑捕获输入 | 优化前字节 | 优化后字节 |
|---|---:|---:|
| TDD 路由 | 63,930 | 16,366 |
| code-generation 路由 | 66,388 | 17,917 |
| code-review 路由 | 65,459 | 17,555 |
| 工具返回 | 288,471 | 138,952 |

离线输入字节减少 **60.4%**。使用相同历史读取序列，包括原来的数据库规则读取，没有假定模型会少发请求；保留约束并补读摘要要求的审查计数契约。模型后续可能请求更多章节或全文，实际 token/耗时需另验。共同提示词前缀、宿主初始输入与自动历史压缩不计入该对比，也未声称已优化。

15 项检查通过，覆盖新增阅读/重入边界、37 个 driver 场景、10 个时间窗口、30 个真实 Core/Gateway 授权与进程场景、7 个自主规则/CLI 场景、3 个已分发 CLI 场景、类型检查及十个 Harness 的 3,163 文件一致性。修正了一条既有回归对只读授权调用数的过时假设，改为逐操作验证权限检查；未放宽授权。

证据见 [工程验收](evals/native-input-2026-11-11/acceptance.json) 和 [离线输入对比](evals/native-input-2026-11-11/input-measurement.json)。根工作流、商城和全局安装未修改；未新建试点、未签发 H5、未运行真实模型。试点入口保持 HOLD，完整业务/UI、真实输入与 P2 successor 资格不由工程测试替代。旧 r13 的精确 stale artifact 原因仍因历史日志缺失而未知，本轮关闭的是已确认的返修分类处理和诊断保留缺口。
