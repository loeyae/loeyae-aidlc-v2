# 全流程减负实施方案与记录（2026-11-12）

依据 [全流程审计](aidlc-flow-audit-2026-11-12.md) 的 A1–A9 实施。目标是让宿主直接工作、减少默认上下文和重复产物，不新增状态、审批、执行计数器或恢复框架。

| 步骤 | 修改范围 | 依赖 | 验收 |
| --- | --- | --- | --- |
| 1 能力入口 | 默认 Skill 元数据/正文与旧受管参考分离；补齐 UI、逆向、调试、交付；专项 DOCX 格式保护保留 | 无 | 所有 Skill 可独立使用；默认描述不要求阶段凭据；旧参考只按显式需求加载 |
| 2 上下文 | work 默认限量摘要，详细信息显式请求；默认帮助仅列常用入口 | 无 | 大量变更默认输出小于 8 KiB，有截断和计数；详细视图可用；只读 |
| 3 工作方法 | 构建/测试/审查无互锁；按相关变化复验；单份业务事实；无进展时改变诊断而非无限同样重跑 | 1 | 纯文档、已有 UI、存量项目的能力说明不要求新建流程证明或阶段记录 |
| 4 宿主安装 | 默认包不注册 Stop Hook；升级仅清理本工具拥有的旧钩子，保留用户配置 | 1 | 临时安装升级保留用户 Hook；默认分发不派发 idle/Stop 工作 |
| 5 定向验证/分发 | 短 CLI 边界、全部能力契约、安装升级及十种分发一致性 | 1–4 | 真实安装包中的入口可运行；不重新跑业务试点或旧长链 |
| 6 实际安装 | 用已验证的本地发布包升级 PATH CLI 与当前 Codex Skill | 5 | 实际解析入口支持 work；Skill/协议与发布包一致；其他配置不变 |

旧 orchestrate/module/autonomy API 和历史状态不删除、不放宽其身份保护；它们的说明隔离到兼容参考。普通宿主执行不读这些记录，不自动接管未知进程。原项目验收标准、真实测试/UI、发布授权继续保留。

默认过程记录只引用真实输出并更新必要业务文档；单元、NFR、基础设施和决策复用现有设计，不为进入下一步重复生成映射/计划。没有相关输入变化或新的诊断目的不重复执行相同检查；反复同样失败时缩小问题、换诊断方法或报告真实外部阻塞，同时继续独立工作。

专项 SVG/DOCX 能力的质量要求不按文件大小删除。SVG 默认使用宿主工具，独立业务语义来源保留；只有明确要求旧 Provider/受管产证时加载其契约。DOCX 仍保留源文件和非样式内容不变约束。

| A7 无进展反复执行 | 增加宿主工作准则：相关输入变化或新诊断目的才重跑；相同失败无新增信息时缩小复现、更换假设或报告真实外部阻塞。没有新增计时器、步骤上限或流程 gate |

| A9 验证覆盖缺口 | 增加全 Skill 默认入口/链接/体积检查、大脏工作区 CLI、真实临时安装升级/卸载、混合钩子及配置保留；验证实际 PATH、已安装文件和完整分发。没有把静态说明检查等同于所有能力的模型实跑 |

### 实测结果

| 项目 | 审计基线 | 本次结果 | 说明 |
| --- | ---: | ---: | --- |
| 16 个精简 Skill 正文合计 | 72,284 B | 19,002 B | 减少 73.7%；旧细节保留在按需参考，不是删除全部规则 |
| 全部 21 个 Skill 正文合计 | 91,194 B | 38,557 B | DOCX、估算、排期等专项内容按需要保留 |
| 默认 work 输出 | 114,205 B | 2,246 B | 减少约 98.0%；当前 1,417 条 Git 状态，明确 truncated=true |
| 默认 help 输出 | 14,407 B | 1,025 B | 减少约 92.9%；完整旧帮助仍可显式请求 |
| work 单次耗时 | 源码 1,451 ms | 源码 1,416 ms；安装入口 850 ms | 非重复基准，受缓存/工作区变化影响，不宣称端到端时间同比下降 |

这里的 B 是 UTF-8 字节，不是模型 tokenizer 的 token 数；Skill 合计也不表示正常会话会一次加载所有 Skill。本次可证明默认输入负担下降，不能据此推算商城 CR 总工时。
