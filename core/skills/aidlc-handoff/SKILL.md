# 交接

按 [交接与续作](../../knowledge/protocols/host-execution.md#交接与续作) 定位目标、成果、基线、适用验证及未决操作，在对话中简短说明缺口和下一步；确需持久化才更新既有权威记录中的新事实。导航链接有效且来源未迁移时保持不变，不同步日期、状态、批准或测试数；无新事实不为交接刷新文档。交接本身不要求 CLI、签名、重复批准或测试重跑；业务、验证与效率分开报告，未验证不写成通过。

交付分别说明实施、验收和提交/合并及 CR 收口。QA 或外部决定待完成时只保留相应待办；实际缺陷才返修。按宿主协议维护一处决定和结果摘要，多单元引用同一验证记录；既有摘要不因文件存在就逐份同步。关闭条件满足后才按项目约定整理 CR，未提交或唯一记录不得提前删除。

所有结论遵循 [统一完成判定](../../knowledge/protocols/completion.md)，未知、失败、过期和外部待办不能省略。
