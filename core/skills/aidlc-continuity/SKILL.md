# 继续实施

按[项目接手与资料收敛](../../knowledge/protocols/project-continuity.md)从原始目标、当前 Git/代码和实际结果恢复工作，识别失效行动提示与重复正文，先核对未决操作，再按已有授权继续实现、测试和返修。可选 `loeyae-aidlc work` 只读查看相关摘要，不是恢复前提；缺交接文档时先调查已有来源，不要求重建阶段身份或补凭据。

只重验相关输入变化，未变结果继续引用。跨人或跨宿主的授权适用性见 [授权边界](../../knowledge/protocols/permissions.md)，收口从全部约定目标反查，遵循 [完成判定](../../knowledge/protocols/completion.md)。
