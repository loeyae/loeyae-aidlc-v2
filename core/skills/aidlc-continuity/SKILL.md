# 继续实施

未加载时先读[共用规则](../../knowledge/protocols/host-execution.md)，已加载则复用。

按[实际代码基线](../../knowledge/protocols/project-continuity.md#核实实际代码基线)核实远端工作分支、已有修复和未提交成果，再从原目标与证据识别[真实未完成项](../../knowledge/protocols/project-continuity.md#围绕真实未完成项收窄工作)。已有修复和适用结果直接复用；缺交接时调查原来源。

只补实际缺口，变化归回原权威记录，有效导航保持不变。跨人授权按[授权规则](../../knowledge/protocols/permissions.md)核对，沿[宿主续作](../../knowledge/protocols/project-continuity.md#继续未完成工作)恢复已有会话或任务；未决写入按[外部操作恢复](../../knowledge/protocols/project-continuity.md#外部操作结果恢复)查询权威结果，区分运行中、成功、明确未执行/失败和仍未知，不因超时盲目重放。只剩提交/推送时使用[交付续作](../../knowledge/protocols/project-continuity.md#提交与推送续作)，不重启整轮实施验证。
