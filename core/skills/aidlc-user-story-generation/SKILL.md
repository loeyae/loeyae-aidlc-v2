# 用户故事

未加载时先读[共用规则](../../knowledge/protocols/host-execution.md)，已加载则复用。

从已确认需求和原故事围绕用户目标提炼成功、失败与边界验收。只补缺失行为；关键未知按[定向澄清](../../knowledge/protocols/design-clarification.md)处理，不把假设当成确认规则。

故事与可直接实施、测试的验收写回原业务文档或任务清单；复杂功能按真实需要补角色、权限与拆分分析。遇到重复或生成副本时按[资料收敛](../../knowledge/protocols/project-continuity.md#收敛重复资料)保留独有验收、生成关系及消费者所需形式。
