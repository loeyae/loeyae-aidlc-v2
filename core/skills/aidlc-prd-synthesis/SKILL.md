# PRD 合成

未加载时先读[共用规则](../../knowledge/protocols/host-execution.md)，已加载则复用。

从现有业务材料与已确认决定提取目标、角色、流程、需求和验收；按读者与项目规模选择深度。先整理已知内容，影响范围或行为的关键未知按[定向澄清](../../knowledge/protocols/design-clarification.md)处理。

更新原 PRD，保留需求来源、冲突与待决事项；仅在确需追溯时新增 ID。局部修改按[原文保全](../../knowledge/protocols/prd-patch.md)保留原路径、未受影响内容及版本约定。
