# 验收执行

未加载时先读[共用规则](../../knowledge/protocols/host-execution.md)，已加载则复用。

从原始需求、已确认变更及约定验收恢复本次目标，包含尚无实现或测试的行为、直接消费者和必要集成。沿[既有验收引用](../../knowledge/protocols/verification.md#沿既有验收引用查全影响)检查覆盖；已有测试清单、diff 和完成摘要不能替代原目标。复用原任务与测试结构，不另建完成矩阵。

核对每项验收的可观察结果、真实入口、环境/数据前提和权限。按项目现有命令与工具执行适用的业务、接口、集成、浏览器或数据检查；约定的安全、视觉和性能条件同样适用。复用[仍适用的证据](../../knowledge/protocols/verification.md#先短回归再集中核验)，保留实际命令、输入、退出码、结果与缺口；Mock 或静态检查不能替代约定真实环境。

断言依据原需求、独立算例或已知业务结果，核对成功、失败、边界与消费者。修复不得自行削弱验收标准；已确认需求变化按[检查标准](../../knowledge/protocols/verification.md#检查标准与行为评估)调整相应检查。高风险或跨边界变化采用独立于实现推理的复核；需要独立审查者时使用宿主能力与现有协作授权，不默认创建多个 Agent。

发现未实现、行为错误或验证缺口，归回原任务并继续设计、实现、诊断和复验；先修当前缺陷，再补受影响检查。缺外部环境、权限或必要决定时，仅保留对应待办并继续独立工作。人工签字或外部批准只有真实发生才算满足。

按[完成判定](../../knowledge/protocols/completion.md)区分实施、本地验证、验收和交付动作；全部约定条件满足后收口。尚有已授权且可执行的必要工作时继续，不以验收报告代替返修。可选 assess 仅汇总已核实事实，不执行或认证验收。
