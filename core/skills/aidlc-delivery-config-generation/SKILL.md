# 交付配置

未加载时先读[共用规则](../../knowledge/protocols/host-execution.md)，已加载则复用。

从项目构建、启动方式与现有配置确定目标所需文件；只澄清缺失的环境、端口、制品及敏感配置来源。新项目可以直接建立必要配置，已有方案增量调整。

生成选定方案实际使用的配置，检验语法、引用、启动命令、权限和密钥处理。结果归入原交付说明或对话；生成与校验不代表已经发布，实际发布核对具体授权。
