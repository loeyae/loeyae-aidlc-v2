# 任务拆分

未加载时先读[共用规则](../../knowledge/protocols/host-execution.md)，已加载则复用。

复用现有合理任务；需要拆分时，按业务目标、代码所有权和独立验证能力划分。优先形成可验证的业务增量，简单工作无需拆分。

每项关联原目标/AC，明确职责、实现入口、验收方式、所需环境/数据、真实依赖、共享契约及写入边界。跨服务协作明确负责人并沿用现有服务边界；在原任务清单维护，约定集成负责人并验证汇合后的完整行为。依赖未就绪只限制相关工作；拆分结束后按原任务终点继续当前可执行项。
