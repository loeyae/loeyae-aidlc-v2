# unit-generation

先复用现有合理单元；简单工作无需强行拆分。按业务目标、代码所有权和独立验证能力划分，跨服务所有权的协作明确接口与负责人，不因此创建新服务。

在现有任务清单或设计中记录职责、依赖和必要验收，足以供宿主安排实施即可；不重复维护 units、manifest、依赖图、故事映射和分解计划多个事实副本。共享改动由宿主协调，必要时使用独立分支/工作树。

依赖未就绪只限制相关工作；已明确范围和批准不逐单元重复询问。

默认由宿主执行，结果和必要业务文档是工作依据；共享边界见 [宿主执行协议](../../knowledge/protocols/host-execution.md)。
