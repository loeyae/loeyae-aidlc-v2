# test-case-derivation

读取本次要求、相关实现和已有测试，识别尚未覆盖的行为、失败模式与边界；来源有重大歧义才询问。直接在项目测试结构中新增或修改测试，不先生成独立用例文件或索引才能编码。

复用已有覆盖，避免把每条文档交叉引用再建一个用例。需要追溯时在现有测试名称/说明中引用要求。纯说明文档无需业务测试或无行为证明，只做适用的结构/链接检查。

输出测试位置、覆盖范围和真实缺口；后续由宿主运行并根据结果返修，不宣称未运行测试通过。

默认由宿主执行，结果和必要业务文档是工作依据；共享边界见 [宿主执行协议](../../knowledge/protocols/host-execution.md)。
