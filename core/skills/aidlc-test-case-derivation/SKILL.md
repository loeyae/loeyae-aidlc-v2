# test-case-derivation

定位本次要求、相关实现和已有测试，按[既有验收引用](../../knowledge/protocols/verification.md#沿既有验收引用查全影响)收集完整候选后判断影响，沿新增消费者 STORY/AC 继续查全，覆盖造数前置、关联断言、失败、边界与并发；不先手选熟悉的用例编号。获准实施时直接在项目测试结构中新增或修改测试；核验范围内的遗漏补入现有权威记录，并核对已定位项与写回结果的差集。来源有重大歧义才询问，不先生成独立用例文件或索引才能继续。

复用已有覆盖，避免把每条文档交叉引用再建一个用例。需要追溯时在现有测试名称/说明中引用要求。说明文档是否影响行为及验收按 [真实验证](../../knowledge/protocols/verification.md) 判断，不制作无行为证明。

输出测试位置、覆盖范围和真实缺口；后续由宿主运行并根据结果返修，不宣称未运行测试通过。

默认由宿主执行，结果和必要业务文档是工作依据；共享边界见 [宿主执行协议](../../knowledge/protocols/host-execution.md)。
