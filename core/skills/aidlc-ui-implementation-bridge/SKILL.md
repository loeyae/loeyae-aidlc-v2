# UI 设计实现

未加载时先读[共用规则](../../knowledge/protocols/host-execution.md)，已加载则复用。

读取设计、目标框架及现有组件，从仓库查明版本、目录和可复用映射，直接落实到代码。

跨端或复杂组件差异需明确布局、交互、尺寸、可访问性和平台限制，必要映射写回原设计或代码说明；不明的平台能力用宿主资料查证。保持指定状态和视觉标准，通过实际运行验证视觉、功能及真实 API 行为。
