复用现有设计或明确页面描述，只补齐影响结果的页面、状态、尺寸与视觉信息。使用已有 CSS、组件和素材生成 HTML，复杂批次按实际需要拆分。

通过真实浏览器检查布局、文字、状态与交互，保存必要 HTML/资源及原设计说明。明确模拟行为与真实后端的区别，Mock 不替代产品的真实 API 和结果验证。
