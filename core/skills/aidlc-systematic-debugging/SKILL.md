# 系统化调试

未加载时先读[共用规则](../../knowledge/protocols/host-execution.md)，已加载则复用。

从真实错误、相关代码和环境开始；缺稳定复现时收集日志或构造最小复现。明显错误直接修复，复杂或反复问题用可证伪的预测逐项检验假设。

保留原失败与根因证据，说明不确定性。先运行能捕捉原症状的短回归，再补受影响检查；断言不得为通过而削弱。相同失败且无新信息时缩小复现或改变诊断。普通修复在对话说明，重大事件或明确要求时再写报告。
