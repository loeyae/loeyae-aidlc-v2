# 定向澄清

目标、范围、业务行为或验收存在关键未知时使用；已有明确决定和验收可直接推进。

先查现有材料与实现，区分当前事实和期望行为。将剩余问题按依赖排序，每轮只问前提已明确的问题，优先影响当前工作的少量选择；给出建议、理由和取舍，允许用户选择其他答案。可查事实自行调查，重大业务或架构选择由用户回答，可逆实现细节自主处理。

收到答复后更新问题及依赖，用具体失败、边界或术语冲突检验理解；尚未回答的前提留到后续轮次。沿用有效决定，只在新证据或范围变化使其失效时重问。未答复、推荐选项和等待超时均不代表用户同意；独立工作继续。

将决定与验收例子补入原 PRD、设计或 STORY/AC，保留未决项及其影响。当前工作所需的关键规则与验收明确后继续实施；用户明确要求深度推敲时再扩展分支，不另建访谈台账或统一确认门槛。

方法借鉴 [mattpocock/skills 的 grilling](https://github.com/mattpocock/skills/blob/main/skills/productivity/grilling/SKILL.md)，按 AI-DLC 的范围、授权和资料复用规则改写。
